## Step 2: Redesign GroundCard (Horizontal Layout)

**Current layout** (vertical):
```
┌──────────────────┐
│   Image Carousel │  (height: 160 grid / 160 list)
│                  │
├──────────────────┤
│ Name             │

```

**New layout** (horizontal):
```
┌────────┬─────────────────────────────┐
│        │  Ground Name          ★ 4.5  │
│ Image  │  [Cricket] [Turf]            │
│ 110px  │  📍 MG Road, Mumbai         │
│        │  📏 2.3 km                   │
│        │  ₹300/hr          ❤️  Book  │
└────────┴─────────────────────────────┘
```

### Design details:
- **Card height**: ~110px fixed
- **Image**: Left side, full height of card, width ~110px, `borderRadius: BorderRadius.horizontal(left: Radius.circular(16))`
- **Info section**: Right side, padding 10-12px
  - **Row 1**: Ground name (bold, 14px) + Rating badge (star icon + number, top-right)
  - **Row 2**: Category chips (horizontal Wrap, max 2)
  - **Row 3**: Location icon + Address (1 line, ellipsis, 11px)
  - **Row 4**: Distance icon + distance text (11px) + Price (₹300/hr bold, right-aligned)
- **Favorite button**: Keep on image, top-right corner (same as current)
- **Remove**: `isGrid` parameter (no longer needed for different layouts), `showAmenities` parameter

### Key changes in `ground_card.dart`:
1. Remove `isGrid` and `showAmenities` parameters (simplify)
2. Change from `Column` layout to `Row` layout
3. Image height becomes card height (110px), width is fixed (110px)
4. Info section uses `Expanded` to fill remaining space
5. Move rating badge from image overlay to info section (top-right of info)
6. Keep distance badge on image overlay (bottom-left)
7. Keep favorite button on image (top-right)
8. Adjust `_buildInfo` to use `Column` with compact rows
9. Remove `AnimatedBuilder` / press animation (simplify) or keep it
